# TikTok micro-episodes — Batch 01

Five 12-second, entertainment-first FollowCheck episodes. Each uses a relatable social-follow mystery, a current-status reveal, a punchline, and a two-second product end card.

## Episodes

1. **The Work Bestie** — shared office lore meets a current one-way follow.
2. **The Group-Chat Ghost** — friends build an absurd investigation board when the export already has the answer.
3. **The Gym Accountability Partner** — matching water bottles take the one-way follow personally.
4. **The Vacation Photo Witness** — the most committed photobomber has a one-way current follow status.
5. **The Cousin Who Watches Everything** — every update gets watched, popcorn included, but the current follow is one-way.

## Publishing

- Upload the clean MP4 from `output/`.
- Use Buffer notification publishing so TikTok opens on the phone at posting time.
- Add a currently popular track from TikTok's Commercial Music Library at 8–12% volume; keep original voice at 100%.
- Enable the promotional-content disclosure because the post promotes FollowCheck.
- Use no more than five relevant hashtags.
- Recheck dialogue intelligibility on phone speakers before publishing.

## Render

Run `./render_batch.sh` on macOS with `ffmpeg` installed. The script uses installed macOS voices, varies character voice and delivery rate, normalizes dialogue, and renders 1080×1920 H.264/AAC masters.

The stories intentionally describe the current mismatch as “one-way.” A current Instagram export cannot establish when or why a follow changed.
