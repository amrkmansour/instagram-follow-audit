Fix the export

Instagram export troubleshooting: missing files, wrong format, and incomplete results

Most comparison errors come from one of four settings: the wrong information category, HTML instead of JSON, a limited date range, or selecting only one of several follower files.

Published August 10, 2026 · Covers FollowCheck’s current ZIP and JSON requirements

“The ZIP does not contain the Followers and following JSON files”

Create a new export and select Connections → Followers and following. The ZIP must contain following.json and at least one numbered follower file such as followers_1.json.

I received HTML files

HTML is convenient to read but not the format FollowCheck parses. Create a new request and choose JSON under Format. Renaming an HTML file to end in .json does not convert it.

The result looks much larger than expected

Confirm that the export date range was All time. A limited range can omit older follower relationships, making more accounts appear not to follow back. The ZIP does not contain a dependable setting that lets FollowCheck verify the range afterward.

There are several followers files

That is normal for larger lists. If you upload the original ZIP, FollowCheck combines all matching followers_N.json files automatically. If you upload loose JSON files, select following.json and every followers_N.json file together.

I selected loose JSON files and received an error

  • Do not mix a ZIP with individual JSON files.
  • Select the following file and every numbered follower file in one selection.
  • Keep the original filenames.
  • Use files from the same export request.

The ZIP is too large

FollowCheck accepts archives up to 50 MB and only needs follower relationship data. Request a smaller export containing only Connections → Followers and following; media quality does not affect these JSON lists.

The export is still being prepared

Wait for Instagram’s completion notice before downloading. Preparation time varies with account size and service conditions. Avoid relying on an incomplete browser download.

Clean restart checklist

Create export → Export to device → Clear all unnecessary categories → Connections: Followers and following → Date range: All time → Format: JSON → Start export.

For screenshots of each setting, use the complete download walkthrough. To understand what the finished comparison means, see unfollowers vs. not following back.

Try the corrected export

FollowCheck reads the original ZIP locally in your browser and combines numbered follower files automatically.
